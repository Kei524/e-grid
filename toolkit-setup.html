SETUP GUIDE

e-Grid Consulting Toolkit 導入マニュアル（Mac / Windows）

Claude Code に「e-Grid Consulting Toolkit」プラグインを導入する手順書。Google Drive の共有フォルダから配布しています（GitHub 公開はしていません）。

対象・所要 e-Grid の共有ドライブにアクセスできる人／約5〜10分。覚える名前は1つだけ：e-grid-consulting-toolkit。

📦 このマニュアルは「Drive／オフライン導入」向け

GitHub 経由の標準導入や、収録スキル・エージェント・ワークフローの一覧は e-Grid Consulting Toolkit（プラグイン概要） を参照してください。

0. 完成イメージ（先に結論）

Claude Code のチャット欄で、最終的に次の2行を実行します（<パス> は各自の環境で取得）。

/plugin marketplace add "<配布フォルダの絶対パス>" /plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

/plugin list に e-grid-consulting-toolkit@e-grid-consulting-toolkit ✔ enabled と出れば完了です。

1. 事前準備（Mac / Windows 共通）

準備内容
Claude Code が使えるターミナルで claude が動く、またはデスクトップアプリ／IDE拡張が入っていること。未導入なら先に社内手順で導入。
Google Drive for Desktop が同期アプリがインストール・ログイン済みで、配布フォルダ egrid_Consulting toolkit_Cloude がPCの Drive 上に見えること。見えない場合はアクセス権を管理者（イーグリッド）に依頼。
（PPTX を作る場合のみ）Python「e-Grid風の PowerPoint を作る」機能を使うときだけ必要（§5）。導入だけなら後回しでOK。

2. インストール手順 — Mac

1

オフライン使用可に

Finderで配布フォルダを右クリック →「このデバイス上で常に使用可能にする」。雲→緑チェックに変わりDL完了まで待つ。

2

絶対パスを取得

フォルダを選択し、option(⌥)＋右クリック →「"…" をパス名としてコピー」。

3

マーケット登録

チャット欄で /plugin marketplace add "<パス>"（ダブルクオートで囲む）。

4

インストール

/plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

5

動作確認

/plugin list で ✔ enabled を確認。セッションを一度再起動。

Step 2 パスの例

/Users/<ユーザー名>/Library/CloudStorage/GoogleDrive-<自分のアドレス>/.shortcut-targets-by-id/<フォルダID>/01_コンサルティング/00_Consulting_OS_/e-Grid_Consulting_OS/egrid_Consulting toolkit_Cloude

※ GoogleDrive-… や <フォルダID> の部分は各自のアカウント・共有設定で変わります。実際の値は Step 2 の操作で取得してください（別法：ターミナルに cd と打ってからフォルダをドラッグ）。

3. インストール手順 — Windows

1

オフライン使用可に

エクスプローラーで配布フォルダを右クリック →「オフラインで使用可能にする」（Google Drive メニュー）。緑チェックまで待つ。

2

絶対パスを取得

フォルダを選択し、Shift＋右クリック →「パスのコピー」（ダブルクオート付きで入る）。

3

マーケット登録

/plugin marketplace add "<パス>"

4

インストール

/plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

5

動作確認

/plugin list で ✔ enabled。セッションを再起動。

Step 2 パスの例

G:\共有ドライブ\…\e-Grid_Consulting_OS\egrid_Consulting toolkit_Cloude

※ Google Drive は G: などの仮想ドライブとして表示され、ドライブ文字・共有ドライブ名は環境で変わります。バックスラッシュ（\）のままで問題ありません。

4. 更新・アンインストール（共通）

更新するとき（配布フォルダが新しくなったら）

/plugin marketplace update e-grid-consulting-toolkit /plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

更新後はセッションを再起動してください。

アンインストールするとき

/plugin uninstall e-grid-consulting-toolkit@e-grid-consulting-toolkit /plugin marketplace remove e-grid-consulting-toolkit

5.（任意）PPTX を作る機能の追加準備

「e-Grid風の PowerPoint を作って」等（egrid-branded-pptx スキル）を使う場合、Python 3 と python-pptx が必要です（実際に生成するときのみ）。

OSコマンド
Mac（ターミナル）python3 --version ／ python3 -m pip install python-pptx
Windows（PowerShell 等）python --version ／ python -m pip install python-pptx

テンプレート本体（e-Grid_PPT_Format.pptx）はプラグインに同梱済みのため別途用意は不要。スライドは正式フォーマットのスライドマスターを継承して生成されます。

6. うまくいかないとき（トラブル対処）

症状原因対処
marketplace add で失敗／フォルダが読めない配布フォルダがクラウド上のみ（雲）で実体が無いStep 1「オフラインで使用可能にする」を実行し、DL完了を待って再実行
install で「マーケットプレイスが見つからない」過去の失敗した登録が残っている下記「登録のやり直し」を実行
パスを貼ったらエラーパスに空白や日本語が含まれ途中で切れているパス全体をダブルクオートで囲む。Mac は option+右クリック、Win は Shift+右クリックで正確に取得
入れたのにスキルが出ないセッション未再起動Claude Code を再起動。/plugin list で enabled を確認
PPTX生成でエラー（ModuleNotFoundError: pptx 等）python-pptx 未インストール§5 の手順で python-pptx を入れる

登録のやり直し（クリーンインストール）

/plugin marketplace remove e-grid-consulting-toolkit /plugin marketplace add "<配布フォルダの絶対パス>" /plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

7. 導入後の使い方（入口）

チャット欄にやりたいことを日本語で書けば、対応するスキルが起動します。

頼み方の例起動するスキル
「e-Grid風のスライドを作成して」「スライドマスターを反映して資料を作って」egrid-branded-pptx
「調査提案書を作成して」interview-research-proposal
「会議メモから議事録を作って」meeting-minutes-creator
「デスクリサーチを実行して」desk-research
「HTMLにして」「4:3スライドにして」html-artifact
「プロジェクトを開始」「次のタスク」project-manager

同梱スキルの一覧と詳しい説明は、配布フォルダ内の README.md を参照してください。

付録. 配布・更新のしくみ（管理者向け）

  • 配布物 ＝ Google Drive フォルダ（egrid_Consulting toolkit_Cloude）。各PCはこのフォルダのローカルパスを marketplace 登録して使う。
  • 編集はメンテナの作業用ローカルコピーで行い、Drive フォルダへ同期して配布する。Drive フォルダを直接編集しない（同期中の読み込み不整合を避けるため）。
  • 名称は「マーケットプレイス名 ＝ プラグイン名 ＝ e-grid-consulting-toolkit」で統一。
