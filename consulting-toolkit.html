e-Grid Consulting Toolkit

コンサルティングプロジェクトの立ち上げから最終報告書まで、ワークフロー全体をAIがサポートする Claude Code プラグイン（スキル・コマンド・エージェント群）。

Claude Code プラグイン スキル 約20 エージェント 5 3フェーズ11ステップ

OVERVIEW

ツールキットの全体像

GitHub リポジトリ：Kei524/e-grid_consulting_toolkit（正本）

要点 調査プロジェクトでは、提案書の論点を軸にインタビューガイド・報告書骨子まで一貫して設計する。各スキルに品質基準が組み込まれ、AIタスクと人間タスクを明確に分離した協調型ワークフローで運用する。

📦 導入方法は2通り

  • GitHub 経由（標準・下記）：/plugin marketplace add Kei524/e-grid-consulting-toolkit
  • Google Drive／オフライン経由：手順は 導入マニュアル（Mac / Windows） を参照

クイックスタート（GitHub マーケットプレイス）

Claude Code のチャット欄で、次の2行を1行ずつ実行するだけで導入できます。

/plugin marketplace add Kei524/e-grid-consulting-toolkit /plugin install e-grid-consulting-toolkit@e-grid-consulting-toolkit

/plugin list に e-grid-consulting-toolkit@e-grid-consulting-toolkit ✔ enabled と出れば完了（反映にはセッション再起動が必要な場合あり）。更新は /plugin update e-grid-consulting-toolkit@e-grid-consulting-toolkit。

覚える名前は e-grid-consulting-toolkit の1つだけ（リポジトリ名 ＝ マーケットプレイス名 ＝ プラグイン名）。

Skills（スキル）

プロジェクト管理

スキル説明トリガー
project-managerワークフローのオーケストレーター。状態管理・進捗追跡を行い、各ステップで適切なスキルを呼び出す「プロジェクトを開始」「進捗確認」「次のタスク」

調査プロジェクト

デスクリサーチとインタビューを組み合わせた調査に対応（技術動向・市場調査・インタビュー中心・デューデリジェンス等）。

スキル説明トリガー

interview-guide-creator提案書の論点に対応したインタビューガイドを作成「インタビューガイドを作成して」
interview-candidate-selector候補者リストから最適な対象者を選定・評価「インタビュー対象者を選定して」
interview-minutes-creator文字起こしと質問リストから詳細なインタビュー議事録を作成「インタビュー議事録を作成して」
report-outline-creator提案書・調査結果から最終報告書の骨子を設計「報告書骨子を作成して」
slide-structure-designerソースからスライドのページ構成をMDで設計。各スライドにレイアウトパターンを割当「スライド構成を設計して」
integrated-analysis-creator調査結果を論点構造に沿って統合分析し、3層ピラミッド構造の最終報告書を作成「最終報告書を作成して」

Agents（エージェント）

特定の役割に特化したサブエージェント。project-manager やワークフローの各ステップから自動的に呼び出されます。

エージェント説明呼び出し
quality-reviewer品質レビュー専門。指定チェック項目＋デフォルト5軸（論理構造・具体性・読み手視点・整合性・網羅性）で評価し、合格／条件付き合格／要修正を判定AIタスク後のレビューゲート（review_level=full）
desk-researcherデスクリサーチ実行専門。Exa／WebSearch／WebFetch／Browser Use で収集し、調査レポートと仮説検証シートを出力Step 3（初期調査）／Step 10（詳細調査）
image-creator画像・図解・データチャート生成。HTML+CSSをPNG化、matplotlibでチャート。イラスト系は生成プロンプト返却「図解して」「グラフを作って」
circleback-minutes-workerCircleback MCP から単一会議のトランスクリプトを取得し議事録MDを生成する専門ワーカーcircleback-meeting-minutes から並列起動
slide-figure-creatorHTMLスライドデッキで、リッチ判定の作り込み図版を1図1エージェントで生成（設計→レンダ→クロップ検証→修正）html-artifact から並列起動

ワークフロー

要点 project-manager が汎用オーケストレーターとして状態管理・レビューゲート・進捗追跡を担い、各ステップの手順はワークフロースキルに委譲する。

状態は3ファイルで管理

ファイル役割
CLAUDE.md静的な基本情報（クライアント名・納期・ファイル配置）。全セッションで自動ロード
workflow.mdプロセス進捗（チェックリスト・成果物リンク・履歴・意思決定）
Output/プロジェクトサマリ.md知識状態（論点・仮説検証状況・リスク・主要発見）。随時更新

与件に応じた3つのパス

A

そのまま使う

定義済みワークフローをそのまま適用

B

調整する

定義済みをベースにステップを追加・省略・順序変更

C

新規設計

AIが与件から新規設計（定義済みを参照パターンに）

スライド化フロー — 4層アーキテクチャ（Step 3／11 の下流）

スライド生成は「内容構成・レイアウトパターン・スライドマスター・実装」の4層に分離され、どの出力経路でも同じレイアウトパターンに従います。

層担当責務
1 内容構成slide-structure-designer1スライド1メッセージの構成MD。各スライドにパターン指定を割当
2 レイアウトパターンslide-pattern-creator / libraryコンテンツエリア構造の正本（structure YAML＋スケルトンHTML）
3 スライドマスターegrid-branded-pptx／html-artifact テーマ表紙・タイトル/メッセージ行・フッター・ロゴ・サイズ・フォント・配色
4 実装html-artifact／image-creator／egrid-branded-pptxパターン（構造）×マスター（スキン）に従って出力

使い方

プロジェクト全体をワークフローで進める

1

与件を配置

あれば Input/ に置く

2

開始

「プロジェクトを開始」→ 名称・クライアント・納期・スコープを入力

3

ワークフロー承認

AIが与件を分析し提案（定義済み or カスタム）→ 承認

4

順に実行

「次のタスク」で各ステップ、完了後に確認・承認／修正。「進捗確認」でいつでも状況把握

推奨・併用

推奨MCP：Exa（セマンティック検索）

desk-research／desk-researcher は Exa のセマンティック検索MCPを Layer 1 の主軸ツールの一つとして利用します。技術文献・研究論文・GitHub・「〜のような事例」型の類似探索・英語ソースに強く、WebSearch（最新ニュース・日本語メディア・公的統計）と相互補完。未設定でも WebSearch／WebFetch で動作します。

併用推奨：Anthropic 公式スキルプラグイン

example-skillsalgorithmic-art, frontend-design, brand-guidelines 等クリエイティブ・デザイン・開発系の参考実装
